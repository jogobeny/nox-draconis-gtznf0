# Resource packs

`IAFCE - XaeroMap Support V1.zip` is modified: Xaero minimap icons remapped to current Ice and Fire texture paths (`textures/entity/`, renamed variants) and a typo in the cockatrice icon fixed, so Ice and Fire mobs no longer show as a missing texture.

`Modpack Fixes.zip` is our own pack (built by `build_fixes.py`) that patches broken mod assets: invalid GeckoLib animations, bad model parents and texture references.
