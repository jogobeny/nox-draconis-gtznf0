# Datapacks

`* fixed.zip` are modified datapacks that fix stuff for 1.21.1 + NeoForge: 1.21 folder names (`recipe/`, `tags/item`, `tags/block`), `neoforge:conditions` for mods we don't have, typos in item ids, and broken JSON.

`NoSpecialVisitors.zip` sets the spawn chance of MineColonies' 27 special tavern visitors to 0, because loading their player skins freezes the server.
